* Installation

The sources for the  bisos.lcnt pip package is maintained at:
https://github.com/bisos-pip/lcnt.

The bisos.lcnt pip package is available at PYPI as
https://pypi.org/project/bisos.lcnt

You can install bisos.lcnt with pip or pipx.

** Installation With pip

If you need access to bisos.lcnt as a python module, you can install it with pip:

#+begin_src bash
pip install bisos.lcnt
#+end_src

** Installation With pipx

If you only need access to bisos.lcnt as a command on command-line, you can install it with pipx:

#+begin_src bash
pipx install bisos.lcnt
#+end_src

The following commands are made available:
/usr/local/bin/beamerExternalExtensions.py
/usr/local/bin/screenstudioWebClientIcm.py

* Capability Bundles (CBM): lcntCore, lcntBases, lcntMultiMedia

bisos.lcnt supplies the CBSs (capability bundle specifications), sboms and assemble steps behind three
CBM leaves of capabilityType =induct=, realm =collective=, at =sys/cbm/collective/induct/<name>/=. Each
leaf is a =cbmProc.spcs= that only points at the CBS (see bisos.capability); it is gated by
=cbmProc.control= (=available=, =enabled=, =disabled=). Materialize them in this order:

|----------------+-----------------------------------------------------------------------|
| Capability     | What it provides                                                      |
|----------------+-----------------------------------------------------------------------|
| lcntCore       | texlive-full, hevea, evince, the Persian fonts (nested fonts sbom)    |
| lcntBases      | =/de/sys/lcnt= and =/lcnt=, linked into the bases BXO (rawBisos only) |
| lcntMultiMedia | reveal.js, display tools; audio on a VM, video recording on a Box     |
|----------------+-----------------------------------------------------------------------|

Each has =<name>-sbom.pcs=, =<name>-assemble.cs= and =<name>-cbs.pcs= in =py3/bin/=, and a pointer
=cbmProc-<name>.spcs= to copy to its leaf. Materialize and verify:

#+begin_src bash
cd /bisos/platform/sys/cbm/collective/induct/lcntCore
./cbmProc.spcs -i cbm_enable
./cbmProc.spcs -i cbm_materialize
lcntCore-assemble.cs -i toolchainCheck       # the verdict: it fails loudly
#+end_src

The legacy scripts and the CBM walker exit 0 even when a step failed, so only =toolchainCheck=
(in each =<name>-assemble.cs=) tells whether a capability is complete.

** lcntBases

The bases BXO on rawBisos is the clone =bxlcnt/bro_lcntBases-rawBisos= (override for tests:
=LCNT_BASES_BXO=). The assemble step makes =/de/sys= and =/lcnt= with sudo. Inside =/de/sys/lcnt= it
links =bxdpt=, =BIB=, =CENTRAL= and =REGISTRY= into the clone, and makes three real directories:
- =lgpc= (Libre Generated Public Content), holding the link =rawBisos= to the clone's
  =lcnt/lgpc/rawBisos=; other hierarchies (such as =bystar=) are added beside it by the user, never inside the clone.
- =lgcc= (Libre Generated Confidential Content), empty: a placeholder for the user's own hierarchy.
- =outputs/all/lists=, where every build keeps =/lcnt/outputs/all/lists/nuBaseDir=.
=lcntBases-assemble.cs -i fullUpdate= repairs a broken link, turns the old =lgpc= link into the real
directory, and refuses to replace a real file or directory. It never links inside the clone.
On the sited BISOS the bases come from a BPO instead and this leaf stays =available=.

** lcntMultiMedia

The environment decides what is installed: Container (PDF and the reveal HTML; display-only tools),
VM (adds audio), Box (adds video recording and editing). It is detected with =systemd-detect-virt=;
override it with =LCNT_MM_ENV=Container|VM|Box=. =lcntMultiMedia-assemble.cs -i environment= reports it
and =-i toolchainCheck= verifies it (and that lcntCore is complete, which it never installs).
The OBS profile and websocket, aeneas, whisper and subed are not done.

* Part of BISOS and ByStar --- ByStar Internet Services Operating System

Layered on top of Debian, *BISOS*: (By* Internet Services Operating System) is a
unified and universal framework for developing both internet services and
software-service continuums that use internet services. See [[https://github.com/bxGenesis/start][Bootstrapping
ByStar, BISOS and Blee]] for information about getting started with BISOS.\\
*BISOS* is a foundation for *The Libre-Halaal ByStar Digital Ecosystem* which is
described as a cure for losses of autonomy and privacy in a book titled: [[https://github.com/bxplpc/120033][Nature
of Polyexistentials]]

/bisos.lcnt/ is part of BISOS.
